输入、指标与输出

用于评测已经生成的预测结果，运行时不依赖训练框架。

评测指标
12 项 COCO AP / AR、逐类指标、crowd、面积区间与 maxDets。
错误诊断
逐图结果、101 点 PR 曲线，以及重复、错类、定位和背景误报的匹配记录。
接入方式
MoonBit 内存 API、native CLI、双模型比较、批量 bbox / segm 和总体／逐类 AP、AR 门禁。

运行 mask 评测示例

需要 MoonBit 0.10.15 兼容工具链。下面的命令比较两份合成 mask 预测。

git clone https://github.com/python123-ops/moondeteval.git
cd moondeteval
moon update
moon run cli --target native -- examples/mask-ground-truth.json examples/mask-baseline.json --iou-type segm --compare examples/mask-candidate.json --diagnostics --pr-curves
